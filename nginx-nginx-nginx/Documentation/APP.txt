================================================================================
ДОКУМЕНТАЦИЯ КОМПОНЕНТА: БЭКЕНД ПРИЛОЖЕНИЕ (APP)
================================================================================

1. ТЕХНОЛОГИЧЕСКИЙ СТЕК
--------------------------------------------------------------------------------
- Базовый образ: python:3.12-alpine. Минимальный размер, отсутствие избыточных 
  системных утилит (повышает безопасность).
- Реализация сервера: Стандартная библиотека http.server (HTTPServer, 
  BaseHTTPRequestHandler). Исключение сторонних фреймворков гарантирует 
  мгновенный запуск и отсутствие уязвимостей в зависимостях.

2. БЕЗОПАСНОСТЬ (Non-Root & Immunization)
--------------------------------------------------------------------------------
- Контейнер запускается под непривилегированным пользователем guest (user: "1000:1000"). 
  В случае компрометации приложения злоумышленник останется заблокирован внутри 
  изолированного пространства пользователя без прав root.
- Файловая система исходного кода смонтирована в режиме Read-Only (./app:/app:ro). 
  Процесс Python физически не может перезаписать или модифицировать файлы своего 
  кода на диске.

3. ЛОГИКА ОБРАБОТКИ ЗАГОВОЛОВ
--------------------------------------------------------------------------------
Приложение обрабатывает GET-запросы, извлекает HTTP-заголовок X-Forwarded-For 
с помощью метода self.headers.get() и возвращает его в формате Plain Text 
(text/plain) клиенту. Это обеспечивает чистый и считываемый вывод при 
тестировании через curl/wget.
